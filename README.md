API Testing Framework with Python and Pytest

This repository contains a robust and scalable API Testing Framework designed for validating RESTful APIs efficiently. Built with Python, pytest, and the Requests library, the framework provides comprehensive test coverage and modular functionality for various HTTP operations, including GET, POST, PUT, and DELETE.

Features:

Modular APIClient for making HTTP requests with built-in error handling and JSON parsing.

Extensive pytest test suite for validating endpoints, query parameters, payloads, and error scenarios.

Support for mocking and parameterized tests to handle real-world API edge cases.
